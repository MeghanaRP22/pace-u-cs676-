# Credibility-Scored Research Assistant (CS676 Project 1)

A Streamlit research chatbot that scores every source it cites with a learned,
explainable credibility model (score, 90% interval, source type, reasons).

Add `ANTHROPIC_API_KEY` under **Settings → Variables and secrets** to enable the
chat. The "Score a list of sources" panel works without a key.
